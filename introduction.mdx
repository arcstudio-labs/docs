## What you can do

With the API, you can build a wide range of integrations and automations:

- **Read and write resources** — Create, retrieve, update, and delete any resource your account has access to.
- **Automate workflows** — Trigger actions in response to events without manual intervention.
- **Sync data** — Keep external systems and databases in sync with real-time or scheduled API calls.
- **Build custom dashboards** — Pull live data into your own UI or analytics tooling.
- **Receive event notifications** — Subscribe to webhooks and react to changes the moment they happen.

<Tip>
  To start making API calls, you'll need an API key. Head to your [dashboard settings](https://app.example.com/settings/api-keys) to generate one, then follow the [Authentication guide](/authentication) to learn how to use it.
</Tip>
