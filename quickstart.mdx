The fastest way to understand what the API can do is to call it. This guide walks you through everything — from grabbing your API key to reading a real response — in five minutes or less. No special tooling required; all you need is a terminal or your favorite HTTP client.

<Note>
  All requests are made to the base URL **`https://api.example.com`**. Every example in this guide uses that base URL, so make sure to replace it if your account is provisioned on a custom domain.
</Note>

## Prerequisites

Before you start, make sure you have:

- An active account. [Sign up here](https://app.example.com/signup) if you don't have one yet.
- An API key. You can generate one from your [dashboard settings](https://app.example.com/settings/api-keys). See the [Authentication guide](/authentication) for full details.

## Steps

<Steps>
  <Step title="Get your API key">
    Log in to your dashboard and navigate to **Settings → API Keys**. Click **Generate new key**, give it a descriptive name (for example, `quickstart-test`), and copy the key value somewhere safe.

    You won't be able to view the full key again after you close that dialog, so store it in a secure location such as a password manager or an environment variable on your machine.

    For a full walkthrough of key generation and best practices, see the [Authentication guide](/authentication).
  </Step>

  <Step title="Make your first request">
    With your API key in hand, run the following command in your terminal. Replace `YOUR_API_KEY` with the key you just copied.

    ```bash
    curl https://api.example.com/v1/resources \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    This sends a `GET` request to the `/v1/resources` endpoint, which returns a list of resources associated with your account.
  </Step>

  <Step title="Read the response">
    A successful request returns an HTTP `200 OK` status and a JSON body that looks like this:

    ```json
    {
      "data": [
        {
          "id": "res_01hxyz1234abcdef",
          "name": "My First Resource",
          "created_at": "2024-06-01T12:00:00Z"
        },
        {
          "id": "res_02hxyz5678ghijkl",
          "name": "Another Resource",
          "created_at": "2024-06-02T09:30:00Z"
        }
      ],
      "meta": {
        "total": 2,
        "page": 1,
        "per_page": 20
      }
    }
    ```

    Each object in the `data` array represents a resource. The `id` field is the unique identifier you'll use in subsequent requests to read, update, or delete that resource.
  </Step>

  <Step title="What's next">
    You've made your first successful API call — here's where to go from here:

  </Step>
</Steps>

## Request examples in multiple languages

The example below shows the same `GET /v1/resources` request in several popular languages and tools. Pick the one that matches your stack.

<CodeGroup>
  ```bash curl
  curl https://api.example.com/v1/resources \
    -H "Authorization: Bearer YOUR_API_KEY"
  ```

  ```python Python
  import requests

  url = "https://api.example.com/v1/resources"
  headers = {
      "Authorization": "Bearer YOUR_API_KEY"
  }

  response = requests.get(url, headers=headers)
  data = response.json()

  print(data)
  ```

  ```javascript Node.js
  const response = await fetch("https://api.example.com/v1/resources", {
    method: "GET",
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
    },
  });

  const data = await response.json();
  console.log(data);
  ```
</CodeGroup>
