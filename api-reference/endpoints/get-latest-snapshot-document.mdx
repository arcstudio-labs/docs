---
title: "Get latest snapshot document"
sidebarTitle: "Get latest document"
description: "Return the current latest snapshot document as JSON or Markdown."
api: "GET /v1/projects/{project_id}/scripts/{script_id}/latest_snapshot_document.{format}"
---

Use `format` as `json` or `md`. This URL points to a moving target and returns `Cache-Control: no-store`.

```bash
curl "https://api.arcstudiopro.com/v1/projects/project_.../scripts/script_.../latest_snapshot_document.json" \
  -H "Authorization: Bearer $ARC_STUDIO_API_KEY"
```

The JSON response has the same shape as [Get snapshot document](/api-reference/endpoints/get-snapshot-document).
