---
title: "List snapshots"
sidebarTitle: "List snapshots"
description: "Return snapshot metadata for a script."
api: "GET /v1/projects/{project_id}/scripts/{script_id}/snapshots"
---

Returns snapshot metadata only.

```bash
curl "https://api.arcstudiopro.com/v1/projects/project_.../scripts/script_.../snapshots" \
  -H "Authorization: Bearer $ARC_STUDIO_API_KEY"
```

```json
{
  "object": "list",
  "url": "/v1/projects/project_.../scripts/script_.../snapshots",
  "has_more": false,
  "data": [
    {
      "id": "snapshot_...",
      "object": "script_snapshot",
      "description": null,
      "revision_color": null,
      "created_at": "2026-06-24T12:00:00Z",
      "formats": ["json", "md"]
    }
  ]
}
```
