The official SDKs wrap the REST API in idiomatic, type-safe client libraries so you can focus on your product instead of writing boilerplate HTTP code. Each SDK handles authentication, serialization, pagination, and error handling for you, and all SDKs stay in sync with the latest API version.

<Note>
  SDKs follow [semantic versioning](https://semver.org). Pin to a minor version in your dependency file (for example, `^1.3.0`) and review the changelog before upgrading to a new major version, as major bumps may include breaking changes.
</Note>

## Python SDK

### Installation

```bash
pip install api-client
```

### Initialization

Create a single client instance and reuse it across your application. The client reads your API key from the `API_KEY` environment variable if you don't pass it explicitly.

```python
from api_client import Client

# Explicit key
client = Client(api_key="YOUR_API_KEY")

# Or set the API_KEY environment variable and call:
client = Client()
```

### List resources

```python
resources = client.resources.list()

for resource in resources.data:
    print(resource.id, resource.name)

# Auto-paginate through all pages
for resource in client.resources.list_all():
    print(resource.id, resource.name)
```

### Create a resource

```python
resource = client.resources.create(
    name="My Resource",
    description="Created with the Python SDK.",
    tags=["sdk", "python"],
)

print(f"Created resource: {resource.id}")
```

### Async usage

The SDK ships a first-class async client for use with `asyncio`, `FastAPI`, and similar frameworks:

```python
import asyncio
from api_client import AsyncClient

async def main():
    async with AsyncClient(api_key="YOUR_API_KEY") as client:
        resource = await client.resources.create(name="Async Resource")
        print(resource.id)

asyncio.run(main())
```

## Node.js SDK

### Installation

<CodeGroup>

```bash npm
npm install @example/api-client
```

```bash yarn
yarn add @example/api-client
```

```bash pnpm
pnpm add @example/api-client
```

</CodeGroup>

### Initialization

```typescript
import { Client } from "@example/api-client";

// Explicit key
const client = new Client({ apiKey: "YOUR_API_KEY" });

// Or set the API_KEY environment variable and call:
const client = new Client();
```

### List resources

```typescript
const response = await client.resources.list();

for (const resource of response.data) {
  console.log(resource.id, resource.name);
}

// Auto-paginate through all pages
for await (const resource of client.resources.listAll()) {
  console.log(resource.id, resource.name);
}
```

### Create a resource

```typescript
const resource = await client.resources.create({
  name: "My Resource",
  description: "Created with the Node.js SDK.",
  tags: ["sdk", "nodejs"],
});

console.log(`Created resource: ${resource.id}`);
```

### Error handling

```typescript
import { ApiError, RateLimitError } from "@example/api-client";

try {
  const resource = await client.resources.create({ name: "Test" });
} catch (error) {
  if (error instanceof RateLimitError) {
    console.error("Rate limit hit. Retry after:", error.retryAfter, "seconds");
  } else if (error instanceof ApiError) {
    console.error(`API error ${error.status}: ${error.message}`);
  } else {
    throw error;
  }
}
```
