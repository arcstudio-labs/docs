Getting your first successful response from the API is the fastest way to understand how everything fits together. This guide walks you through every step — from creating your account to inspecting a real JSON response — so you leave with working code you can build on immediately.

<Note>
  Before you begin, make sure you have generated an API key. If you haven't done that yet, see the [Authentication guide](/authentication) for full setup instructions.
</Note>

<Steps>

  ### Sign up and get your API key

  Create an account at [api.example.com](https://api.example.com) and navigate to **Settings → API Keys**. Click **Generate New Key**, give it a descriptive name (for example, `dev-local`), and copy the value somewhere safe.

  Your API key is shown only once at creation time. If you lose it, you'll need to revoke it and generate a new one.

  Every request you make must include this key in the `Authorization` header:

  ```http
  Authorization: Bearer YOUR_API_KEY
  ```

  ### Install an HTTP client

  You don't need to install anything if you already have **curl** — it ships with macOS, most Linux distributions, and Windows 10+. Verify it's available by running:

  ```bash
  curl --version
  ```

  If you prefer a language-native client, install one of the following:

  ```bash
  # Python
  pip install requests

  # Node.js
  npm install axios
  ```

  ### Make a GET request to list resources

  Fetch the first page of resources from the API to confirm your key is working. Replace `YOUR_API_KEY` with the key you generated in Step 1.

  ```bash
  curl https://api.example.com/v1/resources \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Accept: application/json"
  ```

  A successful response returns `200 OK` with a JSON body that looks like this:

  ```json
  {
    "object": "list",
    "data": [
      {
        "id": "res_01HXYZ1234ABCD",
        "object": "resource",
        "name": "Example Resource",
        "status": "active",
        "created_at": "2024-06-01T12:00:00Z",
        "updated_at": "2024-06-01T12:00:00Z"
      }
    ],
    "has_more": false,
    "total_count": 1
  }
  ```

  ### Inspect the response

  Take a moment to orient yourself in the response structure before moving on:

  | Field | Description |
  |---|---|
  | `object` | Always `"list"` for collection endpoints. |
  | `data` | Array of resource objects matching your query. |
  | `has_more` | `true` when additional pages are available. |
  | `total_count` | Total number of matching records across all pages. |

  Each item in `data` has an `id` field that you'll use to reference individual resources in subsequent requests.

  <Tip>
    Pipe the curl output through `jq` for readable, color-highlighted JSON: `curl ... | jq .`
  </Tip>

  ### Create a resource with POST /v1/resources

  Now send a `POST` request to create your first resource. The request body must be JSON, and you need to set the `Content-Type` header accordingly.

  <CodeGroup>

  ```bash curl
  curl -X POST https://api.example.com/v1/resources \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -H "Accept: application/json" \
    -d '{
      "name": "My First Resource",
      "description": "Created via the API tutorial.",
      "tags": ["tutorial", "getting-started"]
    }'
  ```

  ```python Python
  import requests

  url = "https://api.example.com/v1/resources"
  headers = {
      "Authorization": "Bearer YOUR_API_KEY",
      "Content-Type": "application/json",
  }
  payload = {
      "name": "My First Resource",
      "description": "Created via the API tutorial.",
      "tags": ["tutorial", "getting-started"],
  }

  response = requests.post(url, json=payload, headers=headers)
  response.raise_for_status()
  print(response.json())
  ```

  ```javascript Node.js
  import axios from "axios";

  const response = await axios.post(
    "https://api.example.com/v1/resources",
    {
      name: "My First Resource",
      description: "Created via the API tutorial.",
      tags: ["tutorial", "getting-started"],
    },
    {
      headers: {
        Authorization: "Bearer YOUR_API_KEY",
        "Content-Type": "application/json",
      },
    }
  );

  console.log(response.data);
  ```

  </CodeGroup>

  A successful creation returns `201 Created` with the full resource object in the response body:

  ```json
  {
    "id": "res_01HXYZ5678EFGH",
    "object": "resource",
    "name": "My First Resource",
    "description": "Created via the API tutorial.",
    "status": "active",
    "tags": ["tutorial", "getting-started"],
    "created_at": "2024-06-01T12:05:00Z",
    "updated_at": "2024-06-01T12:05:00Z"
  }
  ```

  Save the returned `id` — you'll use it to retrieve, update, or delete this resource later.

</Steps>
