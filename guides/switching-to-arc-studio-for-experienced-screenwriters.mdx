Welcome! This guide was written to help experienced screenwriters transition to Arc Studio from another screenwriting app. We’ll go over the main features of Arc Studio and link to other guides where you can read about the subjects in greater detail.

Also, we’re happy you’re here! Arc Studio was created because we felt screenwriters deserved a better tool to help tell their stories. If you have any questions, comments, or concerns, [**please let us know**](mailto:hello@arcstudiopro.com). You’ll be pleasantly surprised to learn we actually listen.

# Getting started

<a id="block-833255a2b0a845058ffaab467bf420fe" />

## New Script

To start a new script, first navigate to the Desk. Click `+ Create` in the top right and select `New Script`. Fill out whatever information you want in the pop-up window and click “Create script.”

## Importing an existing script file

If you want to continue working on a script you’ve started in another app, don’t worry. You can easily import FDX, PDF, Fountain/Text, and Word files into Arc Studio. All you have to do is drag and drop the file onto the Arc Studio app window. (You’ll see a notification pop up at the top telling you to “Drop files to import…”)

<video controls src="/videos/migrated/3bd2c426b5428ca87952fd63.mp4" aria-label="Switching to Arc Studio (For experienced screenwriters)" />

Alternatively, you can click `+ Create` and `New Script`, and then `Import` and choose the file on your computer.

# Writing flow

The basic writing flow on the page will feel comfortable and familiar if you’re moving from another screenwriting software. (Below we’ve gone into some detail on the flow, but the quick version of this is it’s very similar to what you’re used to.)

**Scene Headings**

- Typing `int.`, `ext.` or `i/e.` turns an Action element into a Scene Heading.
- After you write the location, hit `Tab` to go to the time of day.
- Hit `Return` to jump from the scene heading to a blank Action element below.
- Once you’ve written a Scene Heading (or Character name), Arc Studio remembers it and the auto-completer offers it as an option as you’re writing the script.
  <video controls src="/videos/migrated/d36c62c3e115a5f5b1c9a1f3.mp4" aria-label="Switching to Arc Studio (For experienced screenwriters)" />

**Action elements**

- Hitting `Return` in an Action element takes you to another Action element below.
  - You can change this and go from an Action element to Character element instead. See: [How Do I Change the Script Flow?](/how-tos/editing-format-and-layout/how-do-change-editing-flow)
- Hitting `Tab` in a blank Action element turns it into a Character element.
  <video controls src="/videos/migrated/822ee8612287671ba509c3d2.mp4" aria-label="Switching to Arc Studio (For experienced screenwriters)" />

**Character elements**

- Hitting `Tab` in a <u>blank</u> Character element turns it back into an Action element.
- Hitting `Tab` <u>after</u> you’ve written the Character name takes you to a Parenthetical.
- Hitting `Return` after you’ve written the Character name takes you to a Dialogue element.
  <video controls src="/videos/migrated/dd5af9388aa6363ebe7b25d6.mp4" aria-label="Switching to Arc Studio (For experienced screenwriters)" />

**Dialogue elements**

- Hit `Tab` in a Dialogue element to go to a Parenthetical.
- Hit `Return` to go to another Character element.
  - If you prefer, you can change this and go from a Dialogue element to an Action element. See: [How Do I Change the Script Flow?](/how-tos/editing-format-and-layout/how-do-change-editing-flow)
    <video controls src="/videos/migrated/73d12451d162ed1bf52aa89e.mp4" aria-label="Switching to Arc Studio (For experienced screenwriters)" />

**Parentheticals**

- Hit `Return` to go from a Parenthetical to a Dialogue element.

## Changing script elements

You can change an element in a few different ways:

<a id="block-6cfa29596fb74dc39d4d660467e8e937" />

### **Via the element menu**

Click the element icon in the margin to the left of the element you wish to change. This opens the element menu. Hover over “**Change element**,” then select which element you want to change it to.

<video controls src="/videos/migrated/2634289d9767d10fa5e1a2de.mp4" aria-label="Switching to Arc Studio (For experienced screenwriters)" />

<a id="block-792a458ec1804237bdc082467e878350" />

### **Via keyboard shortcuts**

When you open the element menu by clicking on the element icon (see above) you’ll see a list of keyboard shortcuts that you can use to change the currently selected element.

(Use `Ctrl` instead of `Cmd` on Windows)

![element shortcuts2x](/images/migrated/b84c47034a6a3bb761b0a0d8.png)

<a id="block-8d793d4aceae4b49ae472d1da261b23d" />

### **Via element mode letter shortcuts**

If you hit `Return` on any <u>empty</u> element, you’ll open up the element mode shortcut list. Type the appropriate letter to change to your desired element.

![shorcut letters2x](/images/migrated/367ca63c84b00385ab68a038.png)

(Action is **A**)

# Focus Mode and Sprint Timers

Enter Focus Mode when you want to eliminate all distractions and get into the zone. Just click the Focus icon in the bottom left, or use the shortcut `Cmd` + `D`

<video controls src="/videos/migrated/e698fb362d2e8fef0c44554f.mp4" aria-label="Switching to Arc Studio (For experienced screenwriters)" />

You can set a sprint timer by clicking the clock next to the Focus icon and selecting a time. Toggle on “Nag me when I don’t write” if you want to be nudged back on task.

<video controls src="/videos/migrated/fac3eb0abeb572c35edc027c.mp4" aria-label="Switching to Arc Studio (For experienced screenwriters)" />

# Draft history, revisions, and tracking changes

Arc Studio’s cloud-based approach gives you powerful tools to help you keep track of all your revisions and changes:

- Instead of folders full of files, all your drafts are in the app and accessible with a single click. Since the drafts are connected you can see what’s changed between the drafts and even bring back work you cut in an old draft.
- Instead of having to email files with elaborate naming conventions between collaborators, everyone comes to the app where your work is centralized.
- We keep tabs on everything in the background so you <u>can’t</u> forget to track changes.

To learn more, check out our comprehensive guide:

[Draft & Revision Management](/guides/draft-and-revision-management)

# Outlining with the Plot Board

The Plot Board helps you figure out and organize all the beats of your story as simply as pinning index cards to a corkboard or writing on a whiteboard, but without the risk of a rogue shoulder brushing against the board and destroying your work.

- Organize your story beats with drag-and-drop cards and structure them in apps.
- You can collect notes on your story elements (characters, storylines, and locations) and tag the relevant beats with those color-coded elements.
- You can read and revise your story structure in paragraph form with Outline view.
- The Plot Board is connected to your script so all your notes on the beats, characters, and storylines are right at hand when you write your scenes. You don’t have to switch between different screens or reference your notes in another app.

For more information, check out our comprehensive guide:

[The Plot Board](/guides/the-plot-board-outlining)

# Multiple Windows

To open a second window, hold down `Shift` and click on whatever you want opened in the second window.

<Tip>
  You cannot have two windows open to the exact same page.
</Tip>

# Settings

Access your Settings by clicking the gear icon in the top right. View all your settings by clicking ‘All settings’ or with the keyboard shortcut `Cmd` + `,` (`Ctrl` + `,` on Windows).
