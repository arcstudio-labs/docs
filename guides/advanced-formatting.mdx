After you’ve familiarized yourself with the basic screenplay formatting elements and how to format them in Arc Studio Pro, we’ve collected some advanced formatting tips and tricks below. Continue reading to learn about:

## Formatting individual paragraphs

To adjust the formatting of an individual paragraph, click the element icon to the left of the paragraph you wish to adjust and select from the “Formatting” options:

<video src="/videos/Adjust-formatting.mp4" controls />

Or access the formatting menu by selecting the paragraph you want to adjust and using the keyboard shortcut  `Cmd + Opt + F` (`Ctrl + Alt + F` on Windows):

Once the formatting menu is open, you can adjust the paragraph margins, alignment, and the top spacing (also set it to a page break).

<a id="block-cd6ce2834c41458c8f7343d2c9d0a2da" />

<video src="/videos/Formatting.mp4" controls />

## Dual Dialogue

Put the cursor on the first of the two Character elements you wish to put in Dual Dialogue. Open the element menu by clicking clicking the element icon in the left margin and select “Make Dual” or use the keyboard shortcut `Cmd + Opt + U` (`Ctrl + Alt + U` on Windows).

To break the dual dialogue, select the character element. Then click the dual dialogue speech bubbles and select “Break Dual,” or use the keyboard shortcut again.

<video src="/videos/Make-and-break-dual.mp4" controls />

<a id="block-d83084247b01422bb2c22b5d06ac3823" />

## Automatic `(CONT'D)`

We don’t enable automatic dialogue `(CONT'D)` by default. If you prefer to have `(CONT'D)` markers added automatically, you can do so in the settings menu.

Click the gear icon and select ‘All Settings’ (or use the keyboard shortcut `Cmd + ,`)

Select 'Document' on the top row and  ‘Page Layout’ on the left and toggle ‘Automatically mark dialogue as (CONT’D)’ to `On`

<video src="/videos/Auto-cont'd.mp4" controls />

## Customizing your script writing flow

In the Settings menu you can set which elements automatically follow an Action or Dialogue element when hitting `Return`.

Access the Settings menu with the keyboard short cut `Cmd + ,` or by clicking the Settings ‘gear icon’ and then clicking ‘All settings’

1. Select the **Account** tab
2. Select **Writing Preferences**
3. Under **Script Flow** use the dropdown menus to customize what automatically follows an Action element and a Dialogue element when you hit `Return`.

![Script Flow@2x](/images/Script-Flow@2x.png "Script Flow@2x")

You can also customize what follows every other element:

1. Select the **Elements** tab
2. Select the element you want to adjust from the list on the left
3. Choose what comes next for **Next element**

![What Follows Elements@2x](/images/What-follows-elements@2x.png "What Follows Elements@2x")

<a id="block-a254fe833c9c46f0aa4d247bbbeb74a0" />

## Adding act breaks

To add the option of including act breaks, change the elements template to ‘Television screenplay’

<Tip>
  Act breaks are automatically included in the Television screenplay template.
</Tip>

Access the Settings menu with the keyboard short cut `⌘ ,` or by clicking the Settings ‘gear icon’ and then clicking ‘All settings’

1. Select the **Document** tab
2. Select **Page Layout**
3. Under **Elements template** choose Television screenplay from the dropdown menu

![TV Template@2x](/images/TV-Template@2x.png "TV Template@2x")

# Creating new script elements

You can add new custom script elements in the Settings menu.

Access the Settings menu with the keyboard short cut `⌘ ,` or by clicking the Settings ‘gear icon’ and then clicking ‘All settings’

1. Select the **Elements** tab
2. Click **\+ Add element** 
3. Name your custom element in the ‘Label’ section and select your desired attributes.
   ![Add An Element@2x](/images/Add-an-element@2x.png "Add An Element@2x")

# Scene numbers

You can add and remove scene numbers in the ‘Production’ section of the Settings menu.

Access the Settings menu with the keyboard short cut `⌘ ,` or by clicking the Settings ‘gear icon’ and then clicking ‘All settings’

1. Select the **Production** tab
2. Select **Scene Numbers**
3. Click assign
4. Choose how you’d like the the scene numbers to appear.

![Scene Numbers@2x](/images/Scene-numbers@2x.png "Scene Numbers@2x")

To remove the scene numbers, select ‘Clear’

See also: [How Do I Manually Change Scene Numbers?](/how-tos/document-script-management/how-do-i-manually-change-scene-numbers)

# Dialogue Numbers

You can add and remove dialogue numbers in the ‘Production’ section of the Settings menu.

Access the Settings menu with the keyboard short cut `⌘ ,` or by clicking the Settings ‘gear icon’ and then clicking ‘All settings’

1. Select the **Production** tab
2. Select **Dialogue Numbers**
3. Click **Assign**
